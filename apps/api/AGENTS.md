# ChordDHT-Tracker — API Worker

Scope: `apps/api/**`. Parent index: `../../AGENTS.md`.

- `src/index.ts` — exports `fetch`/`scheduled` via `ChordDHTTrackerWorker`; re-exports `StaleCleanupWorker` for the `CRON_TASKS` DO binding.
- `src/workers/ChordDHTTrackerWorker.ts` — Hono + Chanfana app; `registerTrackerRoutes()` registers the 15 tracker route classes; `onRequest` wraps `/tracker/*` in a D1 session (`x-d1-bookmark` header round-trip via `createD1SessionEnv`); `onScheduled` forwards to the `CRON_TASKS` DO stub (`DURABLE_OBJECT_NAMESPACE_GLOBAL`).
- `src/endpoints/` — file-routed endpoint classes (one file = one HTTP method; see root `AGENTS.md` routing table). Each exports a class extending `IBaseRoute<TRequest, TResponse, TEnv>` (`IBaseRoute.ts`); the worker registers the class directly.
- Route handlers resolve services via `createRequestScope(env)` from `@chord-dht-tracker/backend-services/composition` (`scope.get(Tokens.X)`); never `new XService(env)` or import `@chord-dht-tracker/backend-data/dao` (enforced by `no-restricted-imports`; type-only DAO imports allowed).
- `src/middleware/` — `index.ts`, `MiddlewareHandlers.ts` incl. `adminAuthentication()` middleware and the `requireAdmin()` guard (throws `UnauthorizedError`).
- `src/generated/spa-shell.ts` — generated by web build; do not edit.

## Auth

- Admin: `Authorization: Bearer <ADMIN_SECRET>` (constant-time comparison in `AuthService`); unlocks full node data. `GET /tracker/admin/verify` checks validity (via `MiddlewareHandlers.requireAdmin`).
- Certificates (opt-in via `CA_PUBLIC_KEY_BASE64`): `POST /tracker/nodes` verifies an embedded certificate when present; `GET /tracker/nodes/seeds?include_cert=true` returns stored certs; `GET /tracker/stats` reports `expiring_cert_nodes`.
- Unauthenticated `GET /tracker/nodes` and `GET /tracker/nodes/:node_id` return only `node_id` (all other fields masked).
